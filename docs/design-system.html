Himalaya Print System

Component Library

Hand-authored visual reference for the Print primitives, built on the Print design tokens. Each primitive renders its variants, sizes, and states on warm paper.

Not load-bearing — the enforcement guard (scripts/check-design.mjs) and DESIGN.md are the enforced source of truth. This catalog may drift; that is accepted.

Variant axis tint | solid; sizes sm | md. PhaseStrip

One cell per series member coloured by its confirmed phase. Coexistence cells use a 2-stop linear-gradient(100deg, A 42%, B 58%); a null phase renders var(--color-ink-faint) (unindexed). The distinct-count caption reads "X throughout", "X → Y" (transition), or the emptyLabel when nothing is indexed. Sizes sm (8 px) and md (7 px, default). Each segment carries an aria-label/title as the accessible second channel.

Phase 2 · Typography

Kicker

Tone axis accent | faint (default faint); polymorphic as prop accepts div | span | h2 | h3 (default div). Base geometry — 700 weight, uppercase, ~11 px — is applied via the .text-kicker class in styles.css; tone selects colour and per-tone tracking: accent = terracotta + 0.13 em; faint = ink-faint + 0.09 em. Section-heading usages should be h2/h3 for the a11y tree; inline/metric labels stay div/span.

Catalog must show: both tones; as div, span, h2, h3 so the polymorphic rendering is clear.

Phase 2 · Surface

Card

Two appearance modes: elevated (elevated=true) renders the single "Plate Lift" object — bg-plate + hairline + rounded-md plus the distinctive warm inset highlight and soft drop shadow (the .card CSS class); the default flat mode (elevated=false) renders bg-plate + hairline + rounded-md with no shadow (Flat-Except-the-Plate). The flat variant accepts a border prop ("hair" | "strong", default "hair") to distinguish inner vs standalone surfaces. Polymorphic via as (div | button | section | li). Nested cards are never allowed.

Catalog must show: elevated vs flat; flat with hair vs strong border; the no-shadow constraint on flat; the nested-card prohibition note.

Elevated card

Plate Lift shadow — the single lifted object on the surface hierarchy. Used for folio cards and primary panels.
