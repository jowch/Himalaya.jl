Himalaya Print System

Component Library

Hand-authored visual reference for the Print primitives, built on the Print design tokens. Each primitive renders its variants, sizes, and states on warm paper.

Not load-bearing — the enforcement guard (scripts/check-design.mjs) and DESIGN.md are the enforced source of truth. This catalog may drift; that is accepted.

Phase 0 · Action

Button

Variant axis solid | accent | ghost | danger. solid is the ink-filled confirm action with paper text (not terracotta); accent is the reserved terracotta grease-pencil action; ghost is default chrome.

Catalog must show: all 4 variants × {rest, hover, focus-visible ring, disabled}; solid reads as ink (not terracotta), accent reads as terracotta, button text reads as paper.

Phase 0 · Data

ScoreBar

Props { value, phase, size }. Color derives from phaseColor(phase) internally; track is always bg-hair; value is clamped 0..1 and rendered as the fill width.

Catalog must show: bar and compact sizes, several phase values (proving color derives from phase), and clamping at value 0 / 0.5 / 1 / out-of-range.

bar · Im3m · value 0.5 → 50%
bar · Square · value 1 → 100%

bar · Ia3d · value -0.2 → clamped 0%
compact · Pn3m · value 0.8

Phase 0 · Status

Dot

Props { label, tone, size }. Tone supplies a semantic color (accent · success · muted · neutral); keeps role="img" + aria-label, and a decorative dot may be aria-hidden to skip the label.

Catalog must show: every tone × size, plus the hollow/neutral ring and an aria-hidden decorative example.

Phase 0 · Feedback

Toast

Four kinds (info · success · warning · error) with a dismiss button. Kind is conveyed by a leading status icon + word + full hairline border — the side-stripe fix (no edge-hue-only severity).

Catalog must show: all four kinds with the leading status icon + word and the dismiss button. (Convention note: the prior border-l-4 hue-only stripe is replaced by the icon+word+hairline treatment, shipped in Phase 0 per the locked side-stripe decision.)
