## 5. Static-serve & dev-root

### Production SPA fallback breaks without the fix — HELD (P0)

**Adversarial verdict HELD (high).** `server.jl:63-71` is the `@get "/**"` SPA catch-all; line 70 unconditionally runs `read(joinpath(dist_dir, "index.html"))` — **no `isfile`/`try`/`catch` guard** (verified the block lines 49-72). The build emits only `dist/print.html` + `assets/` (`vite.config.ts:47` `rollupOptions.input = { print }`; verified `ls dist/` → `assets print.html`, no `index.html`). Julia `read()` on a missing path throws `SystemError` (ENOENT); `Oxygen.serve` has no error handler converting it to a graceful fallback, so it surfaces as **HTTP 500** (the headline says "404" but the claim's own evidence says "500, not 200" — 500 is correct). The `isdir(dist_dir)` guard at `:55` does NOT save it: the directory exists, only the file is absent. **Scope:** breaks every document route including `/` (dynamicfiles serves only files that exist; with no `dist/index.html`, `/` falls through to `/**`). **Mandatory edit:** `server.jl:70` `index.html` → `print.html` (plan §EDIT line 68, P0).

### Dev/e2e are SAFE and bypass server.jl — HELD

**Adversarial verdict HELD (high).** Dev/e2e run Vite (`playwright.config.ts` `webServer.command = "npm run dev"`, baseURL `http://127.0.0.1:5173`), which serves an HTML entry by path regardless of `rollupOptions.input` (`vite.config.ts:43-45` comment: "vite still serves index.html by path regardless of this input"). e2e specs `goto("/sample/10")` etc. resolve via Vite's SPA fallback. **This is exactly why the prod break is masked today** — server.jl is never exercised by e2e.

The plan mitigates: gate on `npm run e2e`; if the dev-root gate fails, fall back to a thin `index.html` that re-exports `src/print/main.tsx` (plan lines 49-50, risk P1 lines 107-108).
