## The grep-gate (load-bearing safety net)

This sweep is the highest over-deletion risk of the redesign. The recurring lesson
(`_topk_phases`, `snapshot.ts`, `UtilityCluster` in prior issues) is that "obviously
dead" things had live consumers. **Rule:** every DELETE below cites the grep proving
zero live (non-test, non-self-definition) `src/` importers. A comment-only or
test-only reference is NOT a live consumer. If re-grep at execution time shows a live
consumer, KEEP it and flag the mislabel — do not delete.
